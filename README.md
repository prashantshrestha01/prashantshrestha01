# 👋 Hi, I'm Prashant

I build security tooling, detection labs, and embedded car-hacking projects. Everything here is my own lab work, documented as I go.

## 🧪 Projects

- **[sentinel-siem-home-lab](https://github.com/prashantshrestha01/sentinel-siem-home-lab)** — 6 KQL detections, scheduled analytic rules with MITRE mappings, and an incident response playbook on a simulated Microsoft 365 tenant.
- **[bec-takeover-ir-lab](https://github.com/prashantshrestha01/bec-takeover-ir-lab)** — End-to-end BEC investigation: synthetic sign-in logs, reconstructed attack timeline, detection queries, containment runbook.
- **[soc-analyst-toolkit](https://github.com/prashantshrestha01/soc-analyst-toolkit)** — Dependency-free Python tools for SOC triage: IOC extraction, phishing-URL scoring, auth-log parsing, alert prioritization.
- **[fusion-ms-can-sniffer](https://github.com/prashantshrestha01/fusion-ms-can-sniffer)** — ESP32-S3 listen-only sniffer for reverse-engineering a 2011 Ford Fusion's MS-CAN body bus (125 kbps).
- **[esp32-can-bridge](https://github.com/prashantshrestha01/esp32-can-bridge)** — ESP32 WiFi CAN bridge with a live WebSocket dashboard.
- **[algo-trading-lab](https://github.com/prashantshrestha01/algo-trading-lab)** — Backtesting sandbox; thousands of strategies tested, validated against the Deflated Sharpe Ratio.
